# TESR Program — programs.tesrshop.com

หน้ารวมโปรแกรมภายในของทีม TESR · Made by TESR

## เพิ่ม/แก้โปรแกรม
แก้ที่ตัวแปร `APPS` ใน `index.html` ที่เดียว (name, desc, url, icon, tags)
ไอคอนใหม่ใส่ไว้ในโฟลเดอร์ `icons/`

## ขึ้นเว็บ (GitHub Pages)
1. สร้าง repo `TESR-Programs` (Public) ใต้บัญชี TESR-Channel
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น branch `main`
3. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save
4. รอ LnwShop เพิ่ม DNS:  `programs  CNAME  tesr-channel.github.io`
5. Settings → Pages → Custom domain: `programs.tesrshop.com` → Save
6. พอ DNS check ผ่าน ติ๊ก **Enforce HTTPS**

ระหว่างรอ DNS ใช้ลิงก์ชั่วคราวได้ที่ https://tesr-channel.github.io/TESR-Programs/
